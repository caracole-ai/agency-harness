# clients/

Un dossier par client : `clients/<slug>/entretien-AAAA-MM-JJ.md`, écrit par le
skill `entretien-metier`.

`clients/index.md` donne à chaque client sa lettre (client A, client B…), dans
l'ordre des premiers entretiens : c'est sous cette lettre, et jamais sous son
nom, qu'un client est cité comme source dans une fiche métier.

Rien de ce dossier n'est versionné, à part ce fichier. Ce qu'un client dit
chez lui reste sur cette machine. Ce qui vaut pour tout son métier remonte à
la main dans `metiers/<métier>/fiche.md`, sans nom et sans chiffre du client.
